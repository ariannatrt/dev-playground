# Laboratorio di sviluppo – Backend

## Struttura dei branch

- `main`  
  Branch di riferimento. Non va modificato direttamente.

- `dev_playground`  
  Branch base del laboratorio. Contiene:
  - struttura del progetto
  - istruzioni
  - esercizi
- `exercise/*`  
  Branch personali degli studenti, creati a partire da `dev_playground`.

## Regole

1. Non lavorare mai direttamente su `main`
2. Non lavorare direttamente su `dev_playground`
3. Ogni attività deve essere svolta su un branch personale `exercise/*`
4. Il lavoro viene consegnato esclusivamente tramite Pull Request
5. Il lavoro deve essere versionato con commit multipli e significativi

## Strumenti richiesti
- Git
- un editor di codice (IntelliJ, VS Code o equivalente)
- accesso a GitHub e a questa repository
